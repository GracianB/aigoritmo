# ✦ 01 · QUÉ ES

**Aigoritmo** es un estudio local cinematográfico en español.

No es un catálogo de avatares.
No es una interfaz de modelos.
No es un wrapper de API con una carta pegada encima.

Es una experiencia construida alrededor de una regla deliberadamente sencilla:

```text
                         CONSULTA
                            │
                            ▼
                    ┌───────────────┐
                    │   PRESENCIA   │
                    │ Arcana / Arcano│
                    └───────┬───────┘
                            │
                            ▼
                    ┌───────────────┐
                    │   UNA CARTA   │
                    │  ARCANO MAYOR │
                    └───────┬───────┘
                            │
                            ▼
                    ┌───────────────┐
                    │ INTERPRETACIÓN│
                    │      LLM      │
                    └───────┬───────┘
                            │
                            ▼
                    ┌───────────────┐
                    │  VOZ · PIPER  │
                    │     LOCAL     │
                    └───────────────┘
```

### **La tecnología está detrás del telón.**

El consultante no necesita conocer el proveedor, el modelo ni la infraestructura.

Solo necesita encontrarse con la presencia.

# 🜂 04 · LA CARTA

La carta aparece localmente.

**Instantánea.**

No depende de una API externa para que la experiencia pueda comenzar.

```text
                    ┌──────────────────┐
                    │  CARTA LOCAL     │
                    │                  │
                    │    INMEDIATA     │
                    └────────┬─────────┘
                             │
                             │ opcional
                             ▼
                    ┌──────────────────┐
                    │   POLLINATIONS   │
                    │                  │
                    │   visual ~8s     │
                    └──────────────────┘
```

La generación remota puede sustituir o enriquecer la representación.

Pero **no controla el inicio de la experiencia**.

# 🧠 05 · CEREBRO INTERCAMBIABLE

El motor de inteligencia es deliberadamente independiente de la experiencia.

```text
                 ┌───────────────┐
                 │  EXPERIENCIA  │
                 │               │
                 │ Arcana/Arcano │
                 └───────┬───────┘
                         │
                         ▼
                ┌──────────────────┐
                │   LLM PROVIDER   │
                └────────┬─────────┘
                         │
          ┌──────────────┼──────────────┐
          ▼              ▼              ▼
       OLLAMA           GROK         CHATGPT
       LOCAL             xAI          OPENAI
```

### Proveedores

| Provider             | Variable   | Arquitectura |
| :------------------- | :--------- | :----------- |
| **Ollama**           | `ollama`   | Local        |
| **Grok / xAI**       | `spacexai` | API          |
| **ChatGPT / OpenAI** | `openai`   | API          |

La presencia no cambia.

La carta no cambia.

Piper no cambia.

**Cambia el cerebro.**

# ◉ 08 · ORBE DE PRESENCIA

El orbe comunica el estado del sistema sin convertirlo en una consola técnica.

```text
IDLE
 │
 │ espera
 ▼
THINKING
 │
 │ consulta
 ▼
SPEAKING
 │
 │ Piper
 ▼
IDLE
```

El usuario no necesita leer:

```text
STATUS = GENERATING_AUDIO
PROVIDER = OLLAMA
STATE = PROCESSING
```

Ve una presencia que responde.

Mucho más elegante. Y, milagrosamente, menos parecido a un panel de administración de 2007.

# 🧭 16 · POR QUÉ EXISTE

La pregunta no era:

> **“¿Podemos conectar un LLM a una interfaz?”**

Eso ya está resuelto.

La pregunta era:

> **“¿Podemos construir una experiencia donde la IA deje de parecer una API?”**

Por eso:

```text
MODELO       → oculto
PROVIDER     → oculto
TOKENS       → ocultos
PIPELINE     → oculto

PRESENCIA    → visible
CARTA        → visible
VOZ          → visible
EXPERIENCIA  → visible
```

La complejidad sigue existiendo.

Simplemente está donde debe estar:

**detrás de la experiencia.**
