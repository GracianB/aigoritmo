# AIGORITMO — ARCANA Demo v3.1

AIGORITMO is a specialized AI avatar demonstration platform. ARCANA is the current showcase persona: a symbolic tarot and reflective-conversation specialist powered locally through Ollama.

## Demo focus

- Conversational AI with session memory
- Avatar state experience
- Interactive tarot: the user reveals cards one by one
- Per-card interpretation and final synthesis
- Media discovery and local avatar video
- Health/readiness endpoints
- CORS-safe local development
- Clean packaging with a local Python project

## Tarot UX

The user does **not** upload images. Tarot cards are generated by the backend and revealed visually, one by one. ARCANA interprets each revealed card in context and then closes the reading with a synthesis.

Vision/image upload remains a future capability and is deliberately excluded from the demo UI.

## Run

```powershell
cd X:\GitHub\systems-lab\aigoritmo\backend
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Open:

`http://127.0.0.1:8000/`

## Models

Set them in `.env`:

- `OLLAMA_CHAT_MODEL=llama3.2:3b`
- `OLLAMA_VISION_MODEL=llama3.2-vision:11b`

## Media

The demo ships with `media/videos/visionfuture.mp4` as a local visual asset. Additional avatar states can be added later without changing the tarot engine.
